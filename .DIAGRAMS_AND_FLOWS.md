## 🔄 DIAGRAMA DE FLUJO PRINCIPAL

```
Usuario WhatsApp
       ↓
WhatsApp Business API (Meta)
       ↓ (Webhook)
Servidor Railway - Orquestador Central
       ↓
¿Conversación transferida?
   ↓ No        ↓ Sí
Selección    IGNORAR
de Agente    (Humano activo)
   ↓
¿Qué agente?
   ↓
├─ AGENTE RECEPCIÓN (Estados iniciales)
│  ├─ Saludo → Solicitar nombre
│  ├─ Validar nombre → Solicitar necesidad  
│  └─ Clasificar con LLM
│     ├─ Pregunta → Transfer SOPORTE
│     └─ Necesidad → Transfer LEADSALES
│
├─ AGENTE SOPORTE (RAG)
│  ├─ Query Vector Database
│  ├─ Similarity Search  
│  ├─ Generate Response (LLM + Context)
│  └─ Respuesta + "¿Algo más?"
│
└─ AGENTE LEADSALES (CRM)
   ├─ Recopilar datos cliente
   ├─ POST → API Leadsales
   ├─ Crear Lead + Asignar Asesor
   ├─ ACTIVAR HANDOFF PROTOCOL
   ├─ Mensaje confirmación
   └─ Estado → TRANSFERIDO
```

## 🔄 ESTADOS DE CONVERSACIÓN

```
[INICIO] → NUEVO
   ↓
NUEVO → RECOPILANDO_NOMBRE (Agente solicita nombre)
   ↓
RECOPILANDO_NOMBRE → RECOPILANDO_NECESIDAD (Nombre validado)
   ↓
RECOPILANDO_NECESIDAD → CONSULTA_RAG (Clasificado como pregunta)
                     → CREANDO_LEAD (Clasificado como necesidad)
   ↓
CONSULTA_RAG → RECOPILANDO_NECESIDAD (¿Algo más?)
            → CREANDO_LEAD (Cambio a necesidad)
   ↓  
CREANDO_LEAD → TRANSFERIDO (Lead creado - ESTADO FINAL)
   ↓
TRANSFERIDO → [FIN] (Humano al control)
```

**Notas:**
- `TRANSFERIDO` = Estado final, agentes IA bloqueados
- Solo asesor humano puede responder después del handoff
- Transiciones válidas están claramente definidas

## 🌐 FLUJO DE APIS

```
ENTRADA: Usuario → WhatsApp API
   ↓
WEBHOOK: WhatsApp API → Railway Server (/webhook)
   ↓
PROCESAMIENTO INTERNO:
├─ Webhook Handler → Agentes IA
├─ Agentes → Gemini API (Clasificar/Generar)
├─ Agentes → RAG Engine → Vector DB
└─ Agentes → Leadsales API (Create Lead)
   ↓
SALIDA: Railway Server → WhatsApp API → Usuario
```

**APIs Utilizadas:**
- **WhatsApp Business API**: Recepción/envío mensajes
- **Gemini API**: Clasificación intenciones y generación respuestas  
- **Leadsales API**: Creación automática de leads
- **Vector Database**: Búsqueda semántica RAG

## 📊 METRICAS Y MONITOREO

**Métricas Clave:**
- Tiempo Respuesta: < 3 segundos
- Volumen Mensual: ~2,100 mensajes  
- Tasa Éxito: > 95%
- Costo Mensual: < $115 USD

**Monitoreo:**
- Logs Estructurados por Agente
- Alertas Automáticas (Errores API)
- Health Checks (/health, /agents/status)

**Alertas:**
- Fallo API Externa
- Latencia Alta  
- Límite Presupuesto

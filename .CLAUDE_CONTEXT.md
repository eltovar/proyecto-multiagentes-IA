## 📋 RESUMEN EJECUTIVO DEL PROYECTO

### Problema Original
Una empresa utiliza WhatsApp Business + Chatling para atender clientes, pero **requiere intervención manual** para transferir conversaciones al CRM Leadsales. Esto genera retrasos y cuellos de botella.

### Solución Desarrollada
Sistema de **3 agentes especializados** que automatiza completamente el flujo:
1. **Agente Recepción**: Saluda, recopila datos, clasifica intención
2. **Agente Soporte**: Responde preguntas con RAG (base de conocimiento)
3. **Agente Leadsales**: Crea leads automáticamente, activa handoff humano

### Restricciones Técnicas CRÍTICAS
- **Presupuesto máximo**: $115 USD/mes
- **Volumen**: ~70 mensajes/día (2,100/mes)
- **Latencia**: < 3 segundos respuesta
- **Disponibilidad**: 24/7

## 🔄 FLUJO DE TRABAJO PASO A PASO

### 1. Recepción de Mensaje
```
Usuario WhatsApp → Meta API → webhook POST /webhook → Orquestador
```

### 2. Orquestador Decision Tree
```python
def process_message(message):
    conversation = get_conversation_state(sender_id)
    
    if conversation.state == TRANSFERIDO:
        return  # Humano al control
    
    selected_agent = select_agent(message, conversation)
    result = await selected_agent.process_message(message, conversation)
    
    if result.transfer_to:
        await handle_agent_transfer(result.transfer_to)
```

### 3. Flujo por Agente

**AGENTE RECEPCIÓN:**
```
NUEVO → "¡Hola! ¿Tu nombre?" → RECOPILANDO_NOMBRE
RECOPILANDO_NOMBRE → "¡Gracias {name}! ¿En qué ayudo?" → RECOPILANDO_NECESIDAD  
RECOPILANDO_NECESIDAD → LLM.classify() → Transfer(SupportAgent/LeadsalesAgent)
```

**AGENTE SOPORTE:**
```
Recibe Transfer → RAG.query(message) → LLM.generate(context) → Respuesta + "¿Algo más?"
```

**AGENTE LEADSALES:**
```
Recibe Transfer → LeadsalesAPI.create_lead() → Handoff Protocol → Estado TRANSFERIDO
```

## 🚨 HANDOFF PROTOCOL (CRÍTICO)

Este es el **mecanismo más importante** del sistema:

```python
# En leadsales_agent.py
async def activate_handoff_protocol(self):
    1. lead_id = await leadsales_service.create_lead(customer_data)
    2. await whatsapp_service.send_message(confirmation_message)  
    3. update_conversation_state(sender_id, STATE_TRANSFERIDO)
    4. # ¡CRÍTICO! Agentes IA se DESACTIVAN para esta conversación
    5. # Asesor humano toma control desde Leadsales
```

**Validación en Orquestador:**
```python
if conversation["state"] == STATE_TRANSFERIDO:
    self.log_action("Conversación transferida", "Ignorando - Humano al mando")
    return  # NO procesar con agentes IA
```

## 🎯 REGLAS DE DESARROLLO PARA CLAUDE

### 1. NUNCA romper el Handoff Protocol
- Estado TRANSFERIDO = conversación bloqueada para agentes IA
- Solo humanos pueden responder después del handoff

### 2. SIEMPRE usar logging
- Cada acción debe ser loggeable para debugging
- Incluir detalles relevantes sin saturar

### 3. MANTENER separación de responsabilidades
- Orquestador = coordinación
- Agentes = procesamiento especializado  
- Servicios = integraciones externas

### 4. VALIDAR entrada siempre
- Webhooks pueden tener formatos inesperados
- APIs externas pueden fallar
- Estados de conversación pueden corromperse

### 5. OPTIMIZAR para el presupuesto
- Minimizar llamadas a Gemini API
- Cachear respuestas RAG cuando sea posible
- Usar embeddings eficientes
